## Notes
- Local number reads dominate dispatches now that `READ_LOCAL_TO_NUMBER` is emitted for coercion-heavy loops.
- Property reads immediately feeding `OBJ_TO_NUMBER` remain the hottest conversion path, confirming this fusion opportunity is still valuable for further superinstruction work.
- The `USHR → OR → WRITE_LOCAL_POP` chain reflects the bit-manipulation microbenchmarks; clustering these handlers together should help layout heuristics.
- No raw `OBJ_TO_PRIMITIVE` executions were recorded, showing the new fused local opcode and other simplifications have eliminated that generic conversion path in the benchmark mix.
